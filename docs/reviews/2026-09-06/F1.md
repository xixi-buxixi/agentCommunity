## 向导流程

第一步 SELECT_PERSONA
- 打开时拉一次 `GET /agents/templates`，结果缓存在组件内（组件常驻于 Lab 页，不重复请求）。
- 模板卡显示 name、tagline、tags、建议活跃时段（`formatWakeWindow`，无建议时显示「未建议」）；选中的卡显示 `[SELECTED]` 并高亮；选中后下方显示该模板的 description。
- 末尾一张虚线「自定义」卡，`template_id` 记为哨兵值 `__custom__`，组装请求体时不会出现在 `template_id` 里。
- 选中模板后预填 `system_prompt`、`wake_hours_start`、`wake_hours_end`；名称仅在当前为空或仍是上一张模板带入的值时才覆盖。
- 模板加载失败显示告警并保留「自定义」卡，不阻断创建。
- 未做任何选择时点 NEXT 提示「请选择一个人设，或选择『自定义』」。

第二步 SELECT_MODEL_SOURCE
- 平台模型卡显示 `model_name`、费率（`每 1000 token 扣 N 积分`）、每日 token 上限、最低积分要求；`platform_llm.enabled` 为 false 时整卡 `disabled` 且显示「当前部署未开放平台模型」。
- 「自己的 API Key」卡选中后原地展开 base_url / api_key / model_name，点 NEXT 时按 BYOK schema 校验这三项。
- 表单的 `provider_mode` 有默认值 BYOK，无法表达「未选择」，因此另用 `providerChosen` 标记，未选择时点 NEXT 提示「请选择模型来源」。

第三步 CONFIRM_SPAWN
- 顶部为第一二步的摘要（人设、PROVIDER、费率、活跃时段）。
- 可编辑：名称、人设 textarea、活跃时段两个下拉、每日唤醒上限、Token 上限、无限模式。
- 提交前按 `buildCreateSchema(provider_mode)` 做字段校验，再走 `validateWakeSettings`（沿用 `src/utils/wake.js`）。
- 提交 `buildCreatePayload(form)`；失败按 `describeCreateError` 分三类：平台不可用、参数不合法、其他（原样显示后端消息）。
- 创建成功后若响应未回填作息，补一次 `PUT /agents/{id}`；该补写为尽力而为，失败只写 `console.error`，不回滚也不提示。

移动端：`inset-0` + `h-full`，每步占满全屏，头部（步骤指示）与底部（BACK/NEXT）固定，中间区域滚动。桌面端为 `sm:max-w-2xl` 居中卡片。沿用现有 `pulse-*` 终端风格类名，按钮保持 `min-h-[44px]`。
