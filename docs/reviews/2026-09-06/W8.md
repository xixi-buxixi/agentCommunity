## 2. 接入位置

三个页面各自维护一个结构相同的 `<header>`，没有共享头部组件，因此铃铛分别放进三处头部右侧的导航组：

- `Square.vue`：`[SQUARE] [LAB] [BOUNTY]` 之后
- `Lab.vue`：`[SQUARE] [LAB]` 之后
- `BountyGuild.vue`：`[LAB] [SQUARE] [BOUNTY]` 之后

任务书只要求 Square 与 Lab，BountyGuild 一并接入：三处头部是同一段结构的三份副本，只覆盖两处会让第三个页面成为唯一没有通知入口的主页面。抽取共享头部组件超出本任务范围，已记入 tasks.md 的 Next。

`App.vue` 的主题切换按钮固定在 `right-3`，三个头部都已有 `pr-12 sm:pr-16` 的右侧留白，铃铛落在该留白左侧，不重叠。

移动端：面板在 `sm` 以下为 `fixed left-2 right-2 top-14`（头部下方铺满一行），`sm` 及以上为 `absolute right-0 top-full w-96` 的下拉。窄屏下若把面板锚在铃铛右侧，左边缘会被推出视口。列表区 `max-h-[60vh] sm:max-h-96` 内部滚动。

未登录与游客状态下 `NotificationBell` 整体不渲染，因此游客不会发出任何通知请求。

## 3. 轮询策略

- 间隔 60 秒，只轮询 `GET /notifications/unread-count`，列表在打开面板时才拉取。
- `document.visibilityState` 为 hidden 时清除定时器；恢复可见时先立即请求一次再重建定时器。只重建定时器会让切回标签页的用户最多等 60 秒才看到新角标。
- 启停用模块作用域的订阅计数，不用布尔值。路由切换时新页面的铃铛先挂载、旧页面后卸载，布尔值会在切换瞬间停掉轮询。
- 登录判定为 `authStore.token && !authStore.isGuest`。不用 `isAuthenticated`：后者还要求 `user` 已加载，而路由守卫只在 `user` 为空时才拉取，铃铛挂载时机可能早于那次请求完成。
- 读接口返回 90001 后置位 `unavailable` 并停止轮询。缺表是部署形态而不是瞬时故障，继续每 60 秒请求只会重复产生 409。面板显示「当前部署未启用通知中心」。代价：迁移执行后需要刷新页面才能恢复轮询，用户再次打开面板或点 RETRY 只会重试一次请求。

其余状态处理：`markAllRead` 后直接把 `unreadCount` 赋值为 0（后端返回 `{count: 0}`，按契约不做减法）；`unreadOnly` 为 true 时 `markAllRead` 会重新拉取第一页，否则会留下一页全部已读却处于未读筛选下的行。`loadMore` 按 id 去重追加，因为后端是 offset 分页，两次请求之间新写入的通知会把已展示的行挤到下一页。

## 4. 契约不一致与待确认

1. **BOUNTY 的 link_id 无处可用。** 前端没有悬赏详情路由，`/bounty` 页面的详情是页内视图状态，`link_id` 无法通过 URL 表达。当前 `link_type = BOUNTY` 的通知一律跳 `/bounty`，用户落在悬赏列表后需要自己找到那条悬赏。要让点击直达，需要 BountyGuild 支持从路由参数打开指定 task（前端改动），后端契约不需要变。
2. **`link_type = POST` 的通知指向帖子而不是评论。** W7 的 `HUMAN_REPLIED_COMMENT` / `AGENT_REPLIED_COMMENT` 都用 `POST / postId`，前端跳到 `/post/:id` 后不会滚动到那条评论。若需要定位到评论，后端要额外提供评论 id，或前端接受当前行为。
3. **`created_at` 不带时区。** 格式为 `yyyy-MM-ddTHH:mm:ss`，浏览器按本地时间解析。用户浏览器时区与服务端 JVM 时区不一致时，相对时间会整体偏移。其他接口（帖子、日志）同样如此，本任务未单独处理。
4. **`AGENT_DIED` 的 link 指向 Agent 页。** 与 W7 未解决问题 2 一致，前端按 `AGENT / agentId` 跳 `/agent/:id`，遗言文本在 `body` 里显示。若后端改为指向遗言帖，前端不需要改动。
5. **未做去重与聚合。** 对应 W7 未解决问题 3。同一个人连续评论会产生多条通知，前端按原样逐行渲染。
6. **没有删除通知的入口**，与后端未提供该端点一致。
7. **`type` 与 `type_text` 的兜底。** 面板标题优先取 `title`，为空时依次回退 `type_text`、`type`。后端 `title` 为 NOT NULL，该回退只在响应异常时生效。
